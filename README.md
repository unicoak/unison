# Прокачка

Платформа для проведения уроков: логин/пароль, роли ученик/учитель/бог, квесты вместо домашки, опыт и уровни, ачивки, расписание и учебный план на год.

## Стек

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · Prisma + PostgreSQL · Auth.js (credentials) · Zod · framer-motion

Деплоится на Timeweb Cloud Apps + Managed PostgreSQL + S3 (см. «Деплой» ниже).

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и заполните:
   - `DATABASE_URL` — строка подключения к PostgreSQL. Локально — любой Postgres; в проде — Timeweb Managed PostgreSQL.
   - `AUTH_SECRET` — сгенерировать: `openssl rand -base64 32`
   - `GOD_EMAIL` / `GOD_PASSWORD` / `GOD_NAME` — первый аккаунт с ролью «бог» (создаётся сидом)
   - `S3_*` — не обязательны локально; нужны только в проде для хранения фото/видео домашек (см. ниже)

2. Установите зависимости и накатите схему БД:

```bash
npm install
npx prisma migrate dev --name init
npm run seed
```

3. Запустите dev-сервер:

```bash
npm run dev
```

Откройте http://localhost:3000, войдите под аккаунтом бога (`GOD_EMAIL`/`GOD_PASSWORD`) — из админки (`/dashboard/manage/users`) можно повысить любого зарегистрировавшегося ученика до учителя.

## Хранение файлов домашек

`src/lib/storage.ts` — при заданных `S3_*` переменных файлы уходят в S3-совместимое хранилище (Timeweb S3 или любое другое, работающее по протоколу S3). Без них (только для локальной разработки) файлы пишутся во временную папку ОС и отдаются через `/api/uploads/[filename]` — **это не для продакшна**: временная папка не переживает перезапуск/передеплой.

Контейнерный хостинг (Timeweb Cloud Apps и подобные) обычно даёт **только на чтение** файловую систему приложения (`/app/public`) — поэтому хранить домашние файлы на диске самого приложения нельзя в принципе, только во внешнем хранилище (S3) или временной директории.

Как настроить S3 на Timeweb:
1. Создать бакет в разделе «S3-хранилище» в панели Timeweb Cloud, тип — публичный
2. Взять `Access Key` / `Secret Key` там же
3. Заполнить в `.env` (или в переменных окружения Cloud Apps): `S3_ENDPOINT=https://s3.twcstorage.ru`, `S3_REGION=ru-1`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET`

## Загрузка больших файлов

Файл сейчас идёт через тело server action — на некоторых хостингах прокси перед приложением всё равно ограничивает размер запроса. Для очень больших видео это может не сработать; в таком случае — присылать ссылку на облако вместо файла, либо со временем перейти на прямую загрузку с клиента в S3 (presigned URL), минуя сервер приложения.

## Роли

- **Ученик** — регистрируется самостоятельно (`/register`)
- **Учитель** — создаётся только повышением роли учеником-«богом» в `/dashboard/manage/users`
- **Бог** — создаётся сидом из `GOD_EMAIL`/`GOD_PASSWORD`, видит и может всё, что и учитель

## Структура

- `prisma/schema.prisma` — модель данных
- `prisma/seed.ts` — лестница уровней, стартовые ачивки, аккаунт бога
- `src/lib/` — бизнес-логика (XP/уровни, ачивки, доступы, хранилище файлов, валидация)
- `src/app/(auth)/` — вход/регистрация
- `src/app/dashboard/` — личный кабинет (ученик) и `dashboard/manage/*` (учитель/бог)

## Деплой

Целевая платформа — **Timeweb Cloud Apps** (автодеплой из git) + **Timeweb Managed PostgreSQL** + **Timeweb S3** для файлов. Команда `npm start` сама применяет миграции и сид при каждом запуске — вручную ничего катить не нужно, только задать переменные окружения из `.env.example` в настройках приложения.

Важно: приложение и база должны быть в одной приватной сети (VPC) в Timeweb, если у базы приватный адрес — иначе Cloud App до неё не достучится.
